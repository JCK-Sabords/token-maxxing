Welcome to token-maxxing.

token-maxxing is a free, open source Claude Code mod that shows your token usage per model, what it would have cost on the Anthropic API, and how many times your Claude subscription paid for itself. To the cent. Cache included. No cap.

What it shows

  • Claude Code token usage per model, this month and all time (Opus, Sonnet, Haiku, Fable).
  • The API-equivalent cost of every reply, at Anthropic's public prices, cache writes and cache reads included. The bill you would pay with your own API key (BYOK).
  • Your subscription ROI: API-equivalent cost divided by what you paid. Green when you're farming, red when you're getting played.
  • A monthly chart, because number go up is the only cardio we do.
  • A profile picture frame with your ROI on it: Flex it.
  • 100% local: it reads the transcripts already on your disk and sends nothing anywhere.

Install

In Claude Code, in a terminal:

/plugin install token-maxxing --marketplace JCK-Sabords/token-maxxing

Then type /tokens. In the Claude desktop app: click + next to the prompt, then Plugins, Add marketplace with JCK-Sabords/token-maxxing, then Add plugin.

Set your plan price (20, 100, 200...) with /plugin configure token-maxxing@token-maxxing to see your ROI.

FAQ

How can I see my Claude Code token usage per model?

Install token-maxxing and type /tokens. A pane shows your tokens per model, this month and all time, with their API-equivalent cost.

How much would my Claude Code usage cost on the API?

token-maxxing prices every reply in your local Claude Code transcripts at Anthropic's public API rates: input, output, cache writes (1.25x for 5 minutes, 2x for 1 hour) and cache reads at each model's own rate.

Is a Claude subscription worth it compared to the API?

Set your plan price and token-maxxing shows the ratio between your API-equivalent cost and what you paid, this month and since your first month. Above x1, the subscription pays for itself.

Does it send my data anywhere?

No. It reads files already on your disk and does arithmetic. It never touches your account or the network.

Why do my numbers look low?

Only local sessions count: cloud sessions and claude.ai chats leave no transcript on your disk. Or you're just not maxxing hard enough.

Does it work in the Claude desktop app and VS Code?

Yes. It works in the Claude Code CLI, the Code tab of the desktop app and the VS Code extension (Claude Code v2.1.287 or later, v2.1.286 in the desktop app).

Is it free?

The mod is free and open source (MIT). The profile picture frame is free with a small signature, or 0.99 EUR in HD without it.
